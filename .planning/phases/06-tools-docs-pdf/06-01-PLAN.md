  <name>Task 2: Create PDF generation engine and Flask blueprint</name>

  <action>
    Per D-01, D-05, D-06, D-07: Create three files for PDF generation and delivery.

    **1. blueprints/tools_docs/pdf_generator.py**

    Import from docs_data: TOOLS_DOCS, TOOL_NAMES, ToolDoc
    Import from weasyprint: HTML, CSS

    Create PDF_CSS constant with professional styling:
    - @page: A4 size, 2cm margins, with @top-center header (section name) and @bottom-center footer (page numbers using counter(page))
    - Cover page: centered content with large title "Quantix Tools Reference Guide", subtitle "Options Trading & Market Analysis Tools", date of generation, version info. Cover uses @page :first with no margin.
    - Table of contents section with dotted leaders and page numbers
    - Body: professional serif/sans-serif fonts (system fonts), 11pt body text
    - Each tool section: colored accent bar at top (using the tool's color_hex), 18pt heading, 12pt subheadings
    - Feature lists: styled with checkmark bullets
    - Code blocks: monospace font, light gray background, padding, border-radius
    - API endpoint tables: bordered table with alternating row colors
    - Page breaks between major tool sections using page-break-before
    - Links styled with the tool's accent color

    Create function generate_tools_pdf(output_path: str | None = None) -> bytes:
    - Build complete HTML document string combining all tool sections
    - Generate cover page HTML with title, subtitle, generation date, platform version
    - Generate table of contents HTML with all 15 tool names
    - For each tool in TOOLS_DOCS:
      - Create section with colored header bar
      - Render overview paragraphs
      - Render key features as styled checklist
      - Render how-to-use as numbered steps
      - Render API endpoints as a table
      - Render example scenario
      - Render configuration if present
      - Render related tools
    - Apply CSS styling
    - If output_path is provided, write PDF to file and return bytes
    - If output_path is None, return bytes only
    - Use weasyprint HTML(string=...).write_pdf() for generation

    Export: generate_tools_pdf function, PDF_CSS constant.

    **2. blueprints/tools_docs/__init__.py**

    Create Flask Blueprint named 'tools_docs' with url_prefix='/api/docs':
    - Import generate_tools_pdf from pdf_generator
    - Import Flask modules (Blueprint, send_file, current_app, after_this_request)
    - Import io for in-memory bytes

    Route GET /tools-pdf:
    - Generate PDF by calling generate_tools_pdf()
    - Wrap in BytesIO
    - Return as downloadable file via send_file with:
      - mimetype='application/pdf'
      - as_attachment=True
      - download_name='quantix-tools-reference-guide.pdf'
    - Set Cache-Control header for 1-hour caching
    - Handle errors gracefully with 500 response
    - Log generation with logger from utils.logging

    Export: tools_docs_bp (the Blueprint instance)

    **3. scripts/generate_tools_pdf.py**

    Standalone CLI script:
    - Add the project root to sys.path so blueprint modules are importable
    - Import generate_tools_pdf from blueprints.tools_docs.pdf_generator
    - Default output path: 'quantix-tools-reference-guide.pdf' in current directory
    - Print status messages during generation
    - On success, print "PDF generated: {output_path}"
    - Handle ImportError gracefully with instruction to run 'uv sync' first
