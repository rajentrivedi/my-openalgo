</read_first>

<action>
Create `services/wishlist_price_monitor_service.py` with:

**Class `WishlistPriceMonitor`:**
- Singleton pattern (threading.Lock, __new__, _initialized flag) — identical to FlowPriceMonitor
- `poll_interval = 30` seconds (configurable, longer than Flow's 5s since wishlist is not time-critical)
- `_monitor_thread: threading.Thread | None` — daemon thread
- `_stop_event: threading.Event`
- `_running: bool`

**Methods:**
- `start()` — start monitoring thread if not running and there are active alerts
- `stop()` — stop monitoring thread
- `_monitoring_loop()` — loop: `_check_all_alerts()` → `_stop_event.wait(poll_interval)`
- `_check_all_alerts()` — call `get_active_alerts()`, group by user_id, for each user resolve auth tokens, fetch quotes, evaluate
- `_check_alert(alert, current_price)` — evaluate condition, send notifications if triggered
- `_evaluate_condition(alert, current_price, reference_price)`:
  - `target_above`: current_price > condition_value
  - `target_below`: current_price < condition_value
  - `percent_up`: ((current_price - reference_price) / reference_price) * 100 >= condition_value
  - `percent_down`: ((reference_price - current_price) / reference_price) * 100 >= condition_value
- `_send_alert_notification(alert, current_price)`:
  - Look up user's Telegram ID via telegram_db.get_user_by_username()
  - Look up user's WhatsApp JID via whatsapp_db.get_user_by_username()
  - Format message: "🚨 Wishlist Alert: {symbol} ({exchange})\nCondition: {condition_type} at {condition_value}\nCurrent Price: ₹{price}\nNotes: {notes}"
  - Send via `telegram_alert_service.send_alert_sync(telegram_id, message)` (non-blocking via ThreadPoolExecutor)
  - Send via `whatsapp_alert_service.send_alert_sync(whatsapp_jid, message)` (non-blocking via ThreadPoolExecutor)
  - Call `update_alert_triggered(alert.id, current_price)`
- `get_status()` — dict with running state, alert counts, poll interval
- `shutdown()` — stop thread, clear state

**Price fetching:** For each user, call `get_auth_token_broker(api_key, include_feed_token=True)` to get (auth_token, feed_token, broker), then `get_quotes_with_auth(auth_token, feed_token, broker, symbol, exchange)`. Use a cache/dict to avoid resolving the same user's auth multiple times per polling cycle.

**Format message:** Use the same Markdown format as telegram_alert_service (bold with `*text*` for WhatsApp, Markdown for Telegram).

**Singleton instance:** `wishlist_price_monitor = WishlistPriceMonitor()`

**Auto-start/stop:** When `create_alert()` is called, call `start()`. When alerts count hits 0, call `stop()`.
</action>

```typescript
export interface WishlistAlert {
  id: number
  wishlist_item_id: number
  symbol: string
  exchange: string
  condition_type: 'target_above' | 'target_below' | 'percent_up' | 'percent_down'
  condition_value: number
  reference_price: number | null
  is_active: boolean
  triggered: boolean
  triggered_at: string | null
  last_checked_price: number | null
  last_checked_at: string | null
  created_at: string | null
}

export interface CreateAlertRequest {
  wishlist_item_id: number
  condition_type: string
  condition_value: number
}

export const wishlistApi = {
  // ... existing methods ...

  getAlerts: async (): Promise<WishlistAlert[]> => {
    const response = await webClient.get<WishlistAlert[]>('/wishlist/api/alerts')
    return response.data
  },

  getAlertsForItem: async (itemId: number): Promise<WishlistAlert[]> => {
    const response = await webClient.get<WishlistAlert[]>(`/wishlist/api/alerts/wishlist/${itemId}`)
    return response.data
  },

  createAlert: async (data: CreateAlertRequest): Promise<{ status: string; alert: WishlistAlert }> => {
    const response = await webClient.post('/wishlist/api/alerts', data)
    return response.data
  },

  toggleAlert: async (alertId: number): Promise<{ status: string; is_active: boolean }> => {
    const response = await webClient.patch(`/wishlist/api/alerts/${alertId}/toggle`)
    return response.data
  },

  deleteAlert: async (alertId: number): Promise<void> => {
    await webClient.delete(`/wishlist/api/alerts/${alertId}`)
  },

  deleteAlertsForItem: async (itemId: number): Promise<void> => {
    await webClient.delete(`/wishlist/api/alerts/wishlist/${itemId}`)
  },
}
```
</action>
